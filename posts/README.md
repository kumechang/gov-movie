# 投稿用テキストと検証レポート（動画ごと）

`build/<id>/`（git 管理外）に書き出された、動画以外のファイルの控え。動画（mp4）は大きいので git には入れていない。

| ファイル | 内容 |
|---|---|
| `post.md` | 投稿用のタイトル・概要欄・固定コメント案（TikTok への投稿は手作業） |
| `report.txt` | 台本・時間・根拠の一覧 |
| `fetch_report.txt` | 外務省データ・Wikipedia・写真ライセンスの検証結果 |
| `narration.json` | 読み上げ文・長さ・読み仮名 |

- 外務省の危険レベルは、各ファイルの取得日時点。**投稿の直前に取り直す**（`python3 src/run.py themes/<id>.yaml`）。
- 再生成すると、この控えとは内容が変わることがある（データの更新）。控えは、そのときの記録。
