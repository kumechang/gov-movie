# ペルー編の流れ（絵コンテ）

「危険と隣り合わせの観光地帯 ペルー編」（`themes/peru_place_risk.yaml`）。全体は約113秒（1080×1920）。冒頭は1枚だけ（[SERIES.md](SERIES.md)「冒頭は1枚だけ」）。

## 一言で

空中の遺跡**マチュピチュ**、インカの首都**クスコ**、独立戦争の最後の戦いの街**アヤクーチョ**。外務省は、**フニン州・ワンカベリカ州・アヤクチョ州・クスコ州の一部（VRAEM地域）などをレベル3**、上記以外（リマ市を含む）を**レベル1**にしている。レベル3の地域まで、マチュピチュは約140km、クスコは約205km、アヤクーチョは約10km（概算）。

## 場面

| パート | 内容 |
|---|---|
| 魅力 | マチュピチュ（標高2,430m・15世紀・クスコの北西約70km）→ クスコ（ケチュア語で「へそ」・インカ帝国の首都・標高3,400m）→ アヤクーチョ（独立戦争最後の戦い・33の教会） |
| 地図 | レベル3（VRAEM地域の郡の円）→ 3つとも「上記以外」でレベル1。アヤクーチョだけレベル3のすぐ近く |
| 注意点 | 主要な観光地で外国人旅行者を狙った強盗・スリ／抗議活動でマチュピチュ行きの鉄道が止まることも |

## 地図の近似

- レベル3の郡（ワンカヨ・コンセプシオン・サティポ・タヤカハ・チュルカンパ・ワンタ・ラ・マル）は、郡の中心の位置の半径18kmの円。クスコ州コンベンシオン郡は「一部地域」としか書かれていないので、VRAEM地域の町ピチャリの位置の円（目安）。
- ロレト州プトゥマヨ郡（レベル3）とレベル2の国境地帯は、この回の地図の範囲の外なので、図には出していない。
