# エクアドル編の流れ（絵コンテ）

「危険と隣り合わせの観光地帯 エクアドル編」（`themes/ecuador_place_risk.yaml`）。全体は約126秒（1080×1920）。冒頭は1枚だけ。

## 一言で

高地の首都**キト**、**赤道記念碑（ミタード・デル・ムンド）**、最大の都市**グアヤキル**。外務省は、コロンビア国境のカルチ県・スクンビオス県・エスメラルダス県北東部を**レベル3**、グアヤキル市・エスメラルダス県北部・トゥルカン市周辺を**レベル2**、ガラパゴス県を除くそれ以外を**レベル1**にしている。キトと赤道記念碑はレベル1、**グアヤキル自体がレベル2**。

## 場面

| パート | 内容 |
|---|---|
| 魅力 | キト（標高2,850m・旧市街は世界遺産、レベル3まで約75km）→ 赤道記念碑（キトの北23km・線は実際の赤道と誤差あり、レベル3まで約55km）→ グアヤキル（最大の都市・最大の港湾都市。レベル2の中） |
| 地図 | レベル3（円）→ レベル2（グアヤキル・エスメラルダス北部・トゥルカンの円）。キト・赤道記念碑はレベル1 |
| 注意点 | グアヤキルの麻薬関連の犯罪組織・凶悪事件／コロンビア国境の県の誘拐・密輸 |

## 地図の近似

- レベル3・レベル2はいずれも円（半径35km／20km）で近似。県境の細かい除外（トゥルカン市と幹線道路など）は図に出していない。
