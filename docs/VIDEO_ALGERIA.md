# アルジェリア編の流れ（絵コンテ）

「危険と隣り合わせの観光地帯 アルジェリア編」（`themes/algeria_place_risk.yaml`）。全体は約119秒（1080×1920）。冒頭は1枚だけ。

## 一言で

**アルジェのカスバ**、ローマ都市**ティムガド**、山あいのローマの街**ジェミラ**。外務省は、リビア・ニジェール・マリ・モーリタニアとの国境地帯とイリジ県イナメナス地区を**レベル4**としている（この回の図の範囲の外）。図で見せているのは、ティジ・ウズ県の山間部・ヘンシュラ県・テベッサ県などを**レベル3**、バトナ県・ブーメルデス県などを**レベル2**、それ以外（アルジェ・ジェミラを含む）を**レベル1**にしている。**ティムガドはバトナ県（レベル2）の中**で、レベル3まで約10km。

## 場面

| パート | 内容 |
|---|---|
| 魅力 | アルジェのカスバ（映画『望郷』の舞台・1992年登録、レベル3まで約60km）→ ティムガド（トラヤヌス帝の碁盤の目の都市・1982年登録、レベル3まで約10km）→ ジェミラ（山の地形に合わせたローマの街、レベル3まで約70km） |
| 地図 | レベル3（円＋県）→ レベル2（県・ティジ・ウズ市周辺）。アルジェ・ジェミラはレベル1 |
| 注意点 | 2013年イナメナスの人質事件（日本人10人死亡）／レベル3の地域にはどのような目的でも渡航しない |

## 地図の近似

- 県は Natural Earth の県境。ティジ・ウズ県の山間部などは円（半径30km／15km）で近似。広大な南部のレベル3は図の範囲外。
