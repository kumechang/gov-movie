# ロードマップ: 台本 → データ取得 → 動画

目標: 「こういうランキングを作りたい」という台本（テーマ案）を入れると、適切な政府統計を選び、データを取り、検証して、動画にする。
積み上げ方（下の層が固まってから上へ）:

| 層 | 内容 | 状態 |
|---|---|---|
| 1. テーマ定義→動画 | `themes/*.yaml` から動画・投稿文まで1コマンド | **完了**（`docs/THEME_SPEC.md`） |
| 2. データ取得 | テーマの `source.fetch` に従い e-Stat から47都道府県の値を取り、2系統で照合 | **完了（e-Stat）**（`src/fetch_estat.py`、`docs/THEME_SPEC.md`）。離婚率・合計特殊出生率で確認 |
| 3. 台本→API選択 | 台本から統計表を探し、取得定義と文言案を作る。人が OK/NG を返す | 未着手 |

## 3 で守ること

- 統計表の取り違えが「間違った数字を載せる」事故になる。取得後は必ず検証レポート（出典・年・単位・最大/最小/全国値・概数か確定数か）を付け、人が承認してから動画にする。
- 商用利用の可否と出典表記ルールを、使う API ごとに確認して `source` に記録する。
- 同じ型の量産はオリジナリティ評価で不利になりうる。テーマごとに冒頭フック・色・切り口を変える。

## 2 の結果（2026-10-07）

- 離婚率2024: e-Stat（人口動態調査 確定数、統計表ID 0003411861）の47県・全国値が、手で読み取った検証済みの値と全件一致。別の表（人口動態総覧 0003411562）の離婚率とも一致し、離婚件数÷人口の再計算とも整合。
- 2本目: 合計特殊出生率2024（統計表ID 0003411598、別表 0003411562 と全件一致）。プレビュー動画の書き出しまで確認。
- 賃金構造基本統計調査は e-Stat 上で2023年までしかなく（2026年10月時点）、最新年の動画には使えない。
- e-Stat appId はユーザーが環境変数 `ESTAT_APP_ID` に登録済み。コード・ログ・キャッシュに出さない（`src/estat.py` が伏せる）。
