# ロードマップ: 台本 → データ取得 → 動画

目標: 「こういうランキングを作りたい」という台本（テーマ案）を入れると、適切な政府統計を選び、データを取り、検証して、動画にする。
積み上げ方（下の層が固まってから上へ）:

| 層 | 内容 | 状態 |
|---|---|---|
| 1. テーマ定義→動画 | `themes/*.yaml` から動画・投稿文まで1コマンド | **完了**（`docs/THEME_SPEC.md`） |
| 2. データ取得 | テーマの `source.fetch` に従い e-Stat 等から47都道府県の値を取って `values` を埋め、2系統で照合 | 未着手（e-Stat appId とネットワーク許可が必要） |
| 3. 台本→API選択 | 台本から統計表を探し、取得定義と文言案を作る。人が OK/NG を返す | 未着手 |

## 3 で守ること

- 統計表の取り違えが「間違った数字を載せる」事故になる。取得後は必ず検証レポート（出典・年・単位・最大/最小/全国値・概数か確定数か）を付け、人が承認してから動画にする。
- 商用利用の可否と出典表記ルールを、使う API ごとに確認して `source` に記録する。
- 同じ型の量産はオリジナリティ評価で不利になりうる。テーマごとに冒頭フック・色・切り口を変える。

## 2 に必要なもの

- e-Stat appId（無料。ユーザーが発行）
- このクラウド環境から api.e-stat.go.jp に届くこと（現状はネットワーク許可制で 403。環境の Network access の許可ドメインに追加が必要）
- VOICEVOX Core の配布物（github.com のリリースアセット。同様に許可が必要）
