## 4. 懸念（重要）
1. **領有権が争われている地域**：ジャンム・カシミール・ラダックは、インド・パキスタン・中国が領有を主張する地域を含む。**地図に国境線や領域を描くと、領有の主張に見える**。Natural Earth の境界は、中立ではない。外務省の文言（「ジャンム・カシミール準州」「管理ライン（LoC）」）を使い、**線や面を描かず、点と地名だけで見せる**案。または、扱わない。
2. **外務省ページの更新が2025年3月25日**。2025年4月のカシミール（パハルガム）での観光客を狙った襲撃、5月のインド・パキスタンの衝突の**前**の記載。画面に最終更新日を必ず出し、「最新」と誤解されないようにする。**公開前に、取り直して、更新されていないかを確認する**。
3. 「分離独立を主張する過激派」「イスラム過激派」の表現は、公式の文言のままにし、決めつけを避ける。
4. 犯罪（睡眠薬強盗・強姦）の記載は、女性旅行者への注意として使えるが、「インドは危険」と煽らない。
