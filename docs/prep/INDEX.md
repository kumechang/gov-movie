## 作る順番についての私の提案
カンボジア → フィリピン → **エジプト** → **タイ** →（インドは保留し、代わりに6位以降のジョージア等）。
- エジプトは、観光地・位置関係・日本人の知名度がそろっている。
- タイは、カンボジア編の続きで見てもらいやすいが、同じ武力衝突の話なので、間隔を空けるか、南部の話と混ぜる。
- インドは、領有権が争われている地域の地図の扱いと、外務省ページの更新日（2025年3月）が論点なので、判断が要る（INDIA.md）。

## 保存してあるデータ
| ファイル | 内容 |
|---|---|
| `data/prep/whs_candidates.json` | タイ・エジプト・インドの世界遺産の一覧（Wikidata。名前・登録年・座標）。登録の漏れがありうる（エジプトは4件しか返らなかった） |
| `docs/prep/PHOTO_CANDIDATES.md`、`data/prep/photo_candidates_raw.txt` | Commons の写真の候補（検索語ごと・ライセンスの種類ごとの一覧。ライセンスは、使うときに API で再確認する。結果が空の検索語もある） |
| `data/prep/distances_thailand.csv` | タイの観光地から、カンボジア国境・マレーシア国境までの距離（Natural Earth の国境線と座標から計算した概算） |
| `data/series_candidates.csv` | 国の候補の元データ（暫定の人気・隣り合わせ度を含む） |

## 共通の注意
- 観光地の座標と「危険レベルの地域に入るか」は、作る前に、Wikidata の座標と、外務省ページの文言で検証する（座標を記憶で書いたものは、各ファイルに「未検証」と記した）。
- 写真は CC0・パブリックドメイン・CC BY だけ。Commons のライセンスと作者は、取得時に確認する。
- 外務省ページの最終更新日は、国ごとに違う。画面に出す。投稿の直前に取り直す。
