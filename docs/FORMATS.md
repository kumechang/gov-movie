# 参考にした動画の型と、国のデータとの対応（2026-10-12 時点）

ユーザーが集めた TikTok の15本を分類し、このシステムで作る型と、裏付けになる国のデータを決めた。
目的は自分用の制作ツール（ユーザーはジャンルにこだわらず、TikTok の主要層にハマってフォロワーが増えること）。

## 型（見せ方）とデータの形

| 系統 | 必要なデータ | 該当した参考動画 | 状態 |
|---|---|---|---|
| ① 一覧型 | 項目×値（＋補足の文字） | 新米の都道府県ランキング、放送事故5選、東大合格者数（横スクロール）、就職の強い大学（カード/Tier/横スクロール）、役職別月給（階段）、世界の危険な場所（危険度★） | **実装済み**（`ranked_list`: grid / scroll / steps）。Tier（段階表）の見せ方は未実装 |
| ② 時系列型 | 年ごとの値 | サッカー日本代表の歴代得点（棒グラフの競争） | 未実装 |
| ③ 場所×年代型 | 同じ場所の年代別画像 | 同じ場所の時代変遷（AI生成の昔の街並み。3,300いいね） | 未実装（国土地理院の年代別空中写真で本物を作る案） |
| ④ 企業プロフィール型 | 1社×複数指標 | EDINET の調べ方、大手企業の紹介 | 未実装（金融庁 EDINET。API キーが必要なはず・要確認） |
| ⑤ 会話劇・キャラ解説 | なし（作り話） | 転職エージェントの会話劇、猫キャラの解説 | 作らない |

反応の目安（ユーザーの報告）: 世界の危険な場所＝1.5万いいね、同じ場所の時代変遷＝3,300いいね。投稿時期・再生数は不明。

## 国のデータの候補（確認済みのこと）

- **e-Stat**: 取得層は実装済み。商用可・出典と加工の表記が必要・API クレジット表示（`source.license`）。賃金構造基本統計調査は e-Stat 上で2023年までしか無い（2026年10月時点）。
- **外務省 海外安全情報オープンデータ**: 国別の危険レベルを XML で配信（5分ごと更新）。営利・非営利を問わず無償で利用可と明記。https://www.ezairyu.mofa.go.jp/html/opendata/index.html 世界地図（国境データ）が別途要る。危険レベルは頻繁に変わるので動画に取得日を入れる。国・人々への偏見に見えない書き方にする。
- **国土地理院 地理院タイル**: 年代別の空中写真（1961〜69年、1974〜78年、2007年以降の年度別など）と最新写真。出典の明示のみで申請不要（タイルをアプリで読み込む場合。動画に画像として使う場合の条件は最終確認が要る）。https://maps.gsi.go.jp/development/ichiran.html
- **EDINET（金融庁）**: 企業の平均年間給与・平均年齢・従業員数・売上高など。API キーの発行と利用条件を未確認。

## 外務省データで作った動画（2026-10-13）と、作り直しの経緯

- 最初は「全207か国をレベル別に読み上げる」段階ボードを作った。情報としては正しいが、約109秒で驚きが弱い、という指摘を受けて作り直した。
- 現在は **G20（日本をのぞく18か国）の危険レベル**（`themes/g20_risk_levels.yaml`）。安全な国から順に発表し、レベル3以上の5か国は「どこが（地域）」「何が危ないか（理由）」までクイズ風に見せる。トルコ・インド・ロシア・メキシコ・サウジアラビアという身近な国の名前が出る意外性と、「ただし一部の地域」という正確さを両立させた。
- 理由の文言は、公式の危険情報ページの本文にそのまま出てくる文言を根拠として必ず付け、毎回自動で一致を検証する。恐怖演出（赤黒・筆文字・血の滴り・揺れ・心音・冥鳴ひまりの声）で見せる。
- 改訂（2026-10-13）: 前段（危険情報なし・レベル1）は国名を読まずにチップをサッと流し、約106秒→約93秒に。背景に、国の形・おおよその位置・危険の種類のアイコン・火の粉を足した（コードで描くので、権利の問題がなく、地域も正確）。実写やAIの画像は、`members[].image` で差し込める（出典の明記が必須）。
- 分かった注意点: ①危険レベルのフラグは「そのレベルの地域を含む」で、国全体ではない。②XMLのフラグが古い国がある（ニューカレドニア、パレスチナ）。公式ページ本文と照合して除外している。③「人気の渡航先」など、公的データで裏付けられないランキングとの組み合わせはしない（e-Stat の出入国統計には、日本人の渡航先の国別が無い。海外在留邦人数は2016年まで）。
- 次の候補: 「何が危ないか」を軸にした別の切り口（紛争・テロ・ギャング・感染症）。感染症（マラリアなど）は、外務省の感染症危険情報や検疫所（FORTH）が元データの候補だが、利用条件と取得方法は未確認。

## 「◯◯だけど危険な国」シリーズと、場所×危険情報の型（2026-10-13）

- G20の動画の反応（ギャップ＋「特定のこの場所」が面白い）を受けて、シリーズ化の方針を決めた。**枠**（ASEAN・OECD・人間開発指数が非常に高い国・GDP上位20…）で複数国を見せる型は `tier_board`、**1か国の人気の場所と危険情報を見比べる**型は `place_vs_risk`（`themes/turkey_place_risk.yaml`、トルコ×イスタンブール、約90秒）。
- 枠に使えるデータ（再利用の許諾を確認済み）: 世界銀行 WDI（CC BY 4.0）、UNDP 人間開発指数（CC BY 3.0 IGO）。使えない/不明: SIPRI・UN Tourism・World Happiness Report・UNESCO WHC（ライセンスが混在・自動取得もできない）・Freedom House・民間指標。外務省の危険レベル3以上の国が、各枠に何か国あるかは、枠を決める前に数える（G7は0、OECDは4、ASEANは4、人間開発指数が非常に高い国は8、など）。
- 「人気の根拠」は主観を載せない。世界遺産・無形文化遺産・映画のロケ地は Wikidata × ja.wikipedia で照合し、写真は Commons のライセンス（CC0 / パブリックドメイン / CC BY のみ）を確認する。「夜景が人気」のような主張は、裏付けがないので、写真の紹介にとどめる。
- 人気の場所が危険情報の対象かどうかを必ず明示する（トルコはイスタンブール県がレベル1。ただし2022年のテロの記載がある）。
- Wikimedia の API は回数制限（429）が出やすい。予備ルートとして、ヘッドレス Chromium で通常のページを読む（`src/browser.py`）。UNESCO の公式ページはボット対策で自動取得できないので、使わない。

## 作る順番（案）と、作らないもの

1. 一覧型エンジン（実装済み）。次は、役職別・学歴別などの「都道府県以外の軸」を e-Stat から取る拡張（階段・カード向け）。
2. 外務省データの取得層 →「世界の危険度ランキング」（世界地図が要る）。
3. 国土地理院の年代別写真 →「同じ場所の変遷」。
4. 推移の棒グラフ（時系列型）。
5. EDINET（企業プロフィール）。
- 作らない: 会話劇、根拠のない大学Tier・順位、権利の怪しい写真・ロゴ・テレビ画面の切り抜き。

## 注意

- 新規アカウントの最初の数本では、再生数が少なくてバラつくため、「層を当てる」ための比較はできない。当たっている型から入り、数十本のまとまりで評価する。評価は、最後まで見られた割合・保存数・コメントなど、母数が少なくても読める指標を使う。フォロワーの属性はフォロワーが増えてから確認する（表示条件は TikTok 公式ヘルプで要確認）。
- 参考動画の末尾には、転職アプリや収益化の宣伝が入っているものがある。収益の出口の設計は別の課題として後で決める。
- 合成音声・AI生成の表示ルール（TikTok の AI 生成コンテンツのラベル）は、投稿前に公式ヘルプで確認する。
