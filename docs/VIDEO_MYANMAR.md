# ミャンマー編の流れ（絵コンテ）

「危険と隣り合わせの観光地帯 ミャンマー編」（`themes/myanmar_place_risk.yaml`）。全体は約144秒（1080×1920）。共通の枠は [VIDEO_TURKEY.md](VIDEO_TURKEY.md)、方針は [SERIES.md](SERIES.md)。

## 一言で

3000を超える仏塔の**バガン**、最後の王朝の都**マンダレー**、洞窟の街**パアン**。外務省は、ラカイン州北部・チン州パレワ地区・シャン州コーカン自治地帯・カチン州ライザー周辺・カレン州ミヤワディ地区・**戒厳令が発令された63地区をレベル3**、それ以外の地域を**レベル2**にしている。バガンはレベル3の地域まで約30km、マンダレーは約20km、パアンは約55km（戒厳令の地区のうち、観光地に近いものだけを図示した概算）。

## 場面

| パート | 内容 |
|---|---|
| 魅力 | バガン（3000を超える仏塔、世界三大仏教遺跡）→ マンダレー（コンバウン朝の最後の都、城壁と堀）→ パアン（カレン州の州都、州で最大かつ最長の洞窟） |
| 地図 | レベル3（ラカイン州北部＋パレワ → ミヤワディ地区 → 戒厳令の63地区（一部のみ図示））→ レベル2（上記以外） |
| 注意点 | 国軍の空爆・迫撃砲による局地的な激しい戦闘／衝突は特定の場所・時間に起きるとは限らず誰でも巻き込まれる可能性／陸路での入国は危険 |

## 地図の近似

- 州は Natural Earth の州境。ラカイン州北部は州を緯度19.9度より北で切った目安。
- 戒厳令の地区は郡（地区）の単位で境界データが無いので、観光地に近い11地区を、Wikipedia の座標を中心にした半径20kmの円で図示（63地区のすべてではない。画面に「図は一部」と明記）。
- シャン州コーカン自治地帯・カチン州ライザー周辺（どちらもレベル3）は、この回の地図の範囲の外なので図に出していない。
- 追加したコード：外務省ページが「●レベル3：」の見出しの後に地域を並べる書式のとき、直前の見出しでレベルを確かめる（`mofa.where_is_faithful`）。
