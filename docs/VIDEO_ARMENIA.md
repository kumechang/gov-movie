# アルメニア編の流れ（絵コンテ）

「危険と隣り合わせの観光地帯 アルメニア編」（`themes/armenia_place_risk.yaml`）。全体は約119秒（1080×1920）。冒頭は1枚だけ。

## 一言で

古い首都**エレバン**、巡礼の地**ホル・ヴィラップ**、谷の縁の**タテヴ修道院**。外務省は、**アゼルバイジャンとの国境周辺地域（ナヒチェバンとの国境地域を含む）をレベル4**、**シュニク州全域と、レベル4地域と接する地域をレベル2**、それ以外（エレバンを含む）を**レベル1**にしている。アゼルバイジャンとの国境まで、エレバン約60km、ホル・ヴィラップ約30km、タテヴ約10km（座標と国境線からの概算）。

## 場面

| パート | 内容 |
|---|---|
| 魅力 | エレバン（紀元前782年の要塞が起源）→ ホル・ヴィラップ（聖グレゴリオスが13年間閉じ込められた穴、トルコ国境のすぐそば）→ タテヴ修道院（9世紀、世界一長い往復式ロープウェイ） |
| 地図 | レベル4（国境周辺）→ レベル2（シュニク州全域と、レベル4に接する地域）。エレバンはレベル1 |
| 注意点 | 国境周辺で発砲事案が断続的に発生／国境周辺の事案が近くの地域に波及するおそれ |

## 地図の近似と、距離の見せ方

- レベル4（国境周辺）は国境から約10kmの帯、レベル2（レベル4に接する地域）は国境から約45kmまでの帯とシュニク州。**公式に範囲の定めがないので目安**。
- 距離は、帯ではなく、**アゼルバイジャンとの国境線そのもの**までの距離で言う（`places[].border_with: AZE`）。最初は「レベル4の地域まで」と言っていたが、帯の幅しだいでタテヴが「0km」になるので、やめた。
