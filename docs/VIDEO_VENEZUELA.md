# ベネズエラ編の流れ（絵コンテ）

「危険と隣り合わせの観光地帯 ベネズエラ編」（`themes/venezuela_place_risk.yaml`）。全体は約125秒（1080×1920）。冒頭は1枚だけ。

## 一言で

世界一のロープウェイの**メリダ**、世界最大の落差の**エンジェルフォール**、三国国境の**ロライマ山**。外務省は、スリア州（マラカイボ市と東部を除く）・タチラ州・ボリバル州の一部（アルコ・ミネロ鉱業地帯とブラジル国境地帯）・アプレ州とアマゾナス州の国境地帯・スクレ州パリア半島を**レベル3**、上記以外を**レベル2**にしている。ロライマ山はブラジルとの国境地帯で、レベル3の中。

## 場面

| パート | 内容 |
|---|---|
| 魅力 | メリダ（世界で最も高く最も長いロープウェイ、レベル3まで約45km）→ エンジェルフォール（落差979m、約40km）→ ロライマ山（標高2,810m、三国国境、レベル3の中） |
| 地図 | レベル3（パリア半島 → スリア州・タチラ州・国境地帯・アルコ・ミネロ）→ レベル2（上記以外） |
| 注意点 | 拳銃を使った強盗（警察官・軍人が行う例も）／流しのタクシーを避ける／デモ・集会に近づかない |

## 地図の近似

- スリア州・タチラ州は Natural Earth の州境。マラカイボ市（半径22km）と「スリア州東部地域」（半径45km）は円で抜いた目安。
- コロンビア・ブラジルとの国境地帯は国境から約25kmの帯（公式に範囲の定めがない）。アルコ・ミネロは概算の多角形、パリア半島は座標の帯。**エンジェルフォールまでの約40kmは、この概算の多角形からの距離**。
- 追加したコード：`border` を、隣国ごとの `{with, km}` のリストで書けるようにした。
